# APK News Reader

Lightweight Android RSS + non-RSS article reader. Kotlin, Jetpack Compose, local-first. Public project, no tracking or server.

**Status:** initial scaffold. APK build is not yet verified.

See [PLAN.md](PLAN.md) and [AGENTS.md](AGENTS.md).

## Build
GitHub Actions runs a debug build. Download the debug APK from the workflow artifacts once the build succeeds. Signed public releases will use protected CI secrets, never keys committed to this repository.
