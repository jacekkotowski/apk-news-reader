## Stash Reader 0.0: build skeleton

**New:** the repo was rebuilt on the recipe of the working CW News app: no Gradle, no libraries, a WebView screen, signed CI builds, an emulator smoke test.

**Try on the phone:** install the APK. You should see a page that says "Stash Reader" and "Hello ... version 0.0". There is no feed yet; it comes in step 1.

**Known limits:** nothing here has been run on a real phone. The emulator smoke test only shows that the app starts and draws the page. The icon is a simple placeholder.
